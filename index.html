ChatBot Platform

LLM-платформа с поддержкой RAG, управления промптами, контекста диалогов и версионируемых миграций базы данных.

Python PostgreSQL SQLAlchemy Alembic LLM RAG

Детали реализации и архитектура

Архитектура и стек

  • Модульная клиент-серверная организация с изолированным слоем данных на базе SQLAlchemy ORM.
  • Версионирование схемы БД через миграции Alembic с сохранением целостности при деплое.
  • Пайплайн retrieval-augmented generation (RAG) для обогащения ответов внешней фактологической базой.

Ключевые технические решения

  • Динамическое управление шаблонами системных промптов без перезапуска приложения.
  • Скользящее контекстное окно сессий для сохранения связности сложных диалогов с LLM.
  • Устойчивая обработка сетевых сбоев провайдеров нейросетевых API и валидация входящих запросов.

Детали реализации и архитектура

Принципы Clean Architecture

  • Строгое разделение на слои: сущности (entities), юзкейсы (use cases) и адаптеры внешних сервисов.
  • Независимость бизнес-правил генерации документов от используемых библиотек рендеринга.
  • Высокое покрытие юнит- и интеграционными тестами с использованием фикстур Pytest.

Оптимизация производительности

  • Кэширование промежуточных шаблонов и часто запрашиваемых справочных реквизитов.
  • Строгая валидация входящих структур данных перед запуском сборки и компиляции файлов.
